# Verificações do perfil

O GitHub Actions confere referências locais dos documentos, a presença das imagens e propriedades estruturais do banner. Execute `node scripts/verify-profile.mjs` na raiz do repositório para repetir a checagem.

As ações têm somente leitura do conteúdo e não publicam sites. Links externos, reprodução visual das animações e funcionamento de projetos externos não são comprovados por esse fluxo. A identidade visual e a apresentação pública do Tecnnic Informa foram preservadas.

Novos projetos devem ter verificações próprias conforme a linguagem, o gerenciador de pacotes e os comandos existentes. Não copiar pipelines com instalação, build ou testes inexistentes.
