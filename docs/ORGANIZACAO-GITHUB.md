## Estrutura

O repositório do perfil contém a apresentação pública, imagens e apresentações de projetos. Cada aplicação pessoal terá seu próprio repositório. O modelo reutilizável fica em modelos/projeto-pessoal e deve ser copiado para a raiz do novo projeto.

## Convenções

- Nomes em minúsculas, sem acentos, com hífens.
- Um projeto por repositório.
- Descrição curta explicando o que o projeto faz.
- Tópicos relacionados à finalidade e à tecnologia realmente utilizada.
- README que permita entender e usar o projeto.
- Issues para tarefas e melhorias; Projects quando houver necessidade.
- main estável, branches curtas e revisão das alterações.
- Releases somente com recursos implementados e verificados.
- Nenhum repositório privado será transformado em público apenas para preencher o portfólio.

## Visibilidade

Começar projetos pessoais em privado. Antes de torná-los públicos, revisar arquivos, histórico, imagens, dependências e condições de distribuição. A apresentação do Tecnnic Informa permanece o trabalho autorizado da empresa no portfólio; outros materiais corporativos ficam fora.
