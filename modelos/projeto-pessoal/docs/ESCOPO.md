# Definição de escopo

Preencha este documento com decisões do projeto antes da implementação. As perguntas abaixo orientam a definição e não representam requisitos já aprovados.

## Problema e público

Qual problema será resolvido e quem usará a solução? Como a tarefa é feita atualmente?

## Primeira versão

Quais recursos são necessários para resolver o problema? Quais ficam para versões futuras?

## Dados e permissões

Quais informações são necessárias? A solução pode usar dados fictícios na demonstração? Qual é a menor permissão necessária para funcionar?

## Critérios de aceitação

Descreva comportamentos observáveis que indicam que a primeira versão funciona. Inclua entradas inválidas, erros de ambiente e recuperação quando forem relevantes.

## Verificação

Defina como cada comportamento será validado e em quais ambientes. Registre resultados reais e limitações; não confunda verificação local com publicação.

## Decisões

Registre a tecnologia escolhida, o motivo e os custos conhecidos. Inclua data e contexto de decisões que afetam manutenção ou uso.
